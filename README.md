# Spellbound By Lucy

A static website for Spellbound By Lucy, featuring service information, contact details, after-care guidance, and a celestial garden design.

## Project structure

```text
.
├── assets/
│   ├── css/styles.css
│   ├── images/Logo.png
│   └── js/script.js
└── index.html
```

## Run locally

Open `index.html` in a browser, or serve the repository root with any static file server.

## Publish with GitHub Pages

In the repository settings, open **Pages** and configure deployment from the desired branch and the repository root (`/`). The site has no build step or runtime dependencies.
